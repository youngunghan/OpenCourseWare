## 접근 점검의 범위

기존646 URL 중 HTTP404 11개·GitHub404 1개, 익명 보기401 6개, HTTP200이지만 PDF 파싱 실패1개, eTL 미요청1개를 구분했다. 이전된 GitHub 주소1개는 현재 주소로 확인했다. 첫 연결이 실패한 자료구조 페이지는 재시도 성공 결과를 기록했다. 나머지 결과도 HTTP200, GitHub 메타데이터, PDF 구조 확인 등 증거 수준을 분리한다.

PDF336개는 파서로 구조를 읽고 앞부분 텍스트 추출을 시도했다. 스캔·폰트 인코딩 때문에 텍스트가 충분하지 않은 경우도 있어336개를 내용 전체 정독 완료라고 표현하지 않는다. PPTX는 ZIP/XML 구조, 노트북은 JSON 구조를 확인했으며 실행·렌더링하지 않았다. 영상은 공개 링크 응답과 공식 수업 연결을 확인했으나 재생하지 않았다. 로그인·쿠키·인증정보를 사용하지 않았고 비공개 LMS를 조회하지 않았다.

모든 강의·과제 파일의 정답성, 학생 구현의 실행 결과, 전체 학기 자료의 완전성, 다른 환경에서의 익명 이용 가능성은 검증하지 않았다. [데이터와 분류 기준](methodology.md) 및 각 항목의 접근 범위를 함께 읽는다.
