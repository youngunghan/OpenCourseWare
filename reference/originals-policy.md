# 원본 파일 보관 기준

[첫 화면](../README.md)

2026-11-04 사용자 요청에 따라 링크 목록과 함께 재배포 가능한 원본 파일을 저장한다. 공개되어 있다는 이유만으로 모든 강의록·교재·학생 보관본을 재배포하지 않는다. 원문 라이선스·허용 범위가 확인된 파일만 보관하고, 나머지는 확인 상태와 미수집 사유를 기록한다.

- 원본 바이트를 수정하지 않는다. GitHub 파일은 고정 커밋·경로·Git blob SHA-1·SHA-256으로, 웹 자료는 원문 URL·확인일·SHA-256으로 식별한다. `.gitattributes`의 `materials/** -text`는 Git의 줄바꿈 변환을 막기 위한 설정이다.
- 원출처의 LICENSE·COPYING·COPYRIGHT 등 이용 조건을 함께 보존한다. 중첩된 개별 파일·디렉터리 라이선스가 있으면 그 조건을 우선한다. 이 저장소의 메타데이터나 다른 자료의 라이선스로 덮어쓰지 않는다.
- 학생이 올린 교수 강의록·문제집, 웹사이트 테마, 설치 프로그램, 데이터셋·사전학습 모델은 각각 권리 범위가 다를 수 있다. 원출처가 명확한 소스·실습 문서와 구분해 판단한다. 라이선스 미확인은 재배포 금지 확정이나 자료 부재를 뜻하지 않는다.
- GitHub 원본은 강의나 과제의 정확성·안전성·실행 가능성을 검증한 제품 코드가 아닌 수집 자료다. 수집·검수 중 원본 프로그램·노트북·빌드·설치·컨테이너·매크로를 실행하지 않는다. 원본 스크립트를 자동 실행하는 워크플로도 만들지 않는다.
- 공개 압축 배포본을 보관할 때는 경로 이탈·절대 경로·링크·확장 크기를 확인한다. 원본 전체 압축파일과 읽기용 일부 파일을 함께 보관하면 그 차이와 포함 관계를 표시한다. 압축파일 안의 항목을 각각 별도 다운로드 파일로 부풀려 세지 않는다.
- 비공개 LMS·로그인 토큰·쿠키·학내 인증·접근 제한은 수집 범위 밖이다. 실제 인증정보가 발견된 파일은 원본이라고 주장하며 수정·삭제하지 않고 보관 대상에서 제외한다. 학생 명부·타인의 비공개 성적·불필요한 개인정보 자료도 보관하지 않는다. 원문 코드·보고서의 일반적인 저자 표시와 공개된 과제 파일명은 보존될 수 있다.
- 전체 카탈로그의 모든 자료를 수집했다고 주장하지 않는다. 원본을 일부 보관한 항목과 보관하지 못한 항목을 나누고, 교재 현재 배포본을 과거 학기 교수 배포본과 동일하다고 표시하지 않는다. 원본이 추가되어도 기존 분류와 `full_semester_verified=false`는 별도 근거 없이 바꾸지 않는다.
- 보관 파일별 해시·원출처·권리 근거·크기를 검증하고 고정 커밋을 독립 검수한다. 바이너리 파일은 컨트롤러의 텍스트 diff 검수와 분리해 원본 바이트·매니페스트·권리 범위의 별도 검수를 받는다. 텍스트 검수 승인만으로 PDF 모든 쪽이나 코드 실행을 검증했다고 주장하지 않는다.

일반 Git의 파일 크기 제한을 넘는 파일이나 유료 저장공간이 필요한 자료는 별도로 기록한다. 자동으로 저장공간을 구매하거나 LFS 과금을 설정하지 않는다. 저작권자의 수정·삭제 요청이나 더 명확한 허용 근거가 있으면 해당 범위를 갱신한다.
