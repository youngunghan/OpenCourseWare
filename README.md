## 읽을 때 구분할 점

**“함께”는 양쪽 일부 자료가 있다는 뜻이며 한 학기 전체 완비를 뜻하지 않는다.** 문제·코드 뼈대·학생 풀이·과제 해설·프로젝트 수행 지침을 상세 항목에서 구분했다. 서울대 함께 24에는 프로젝트 지침 2·과제 해설만 1이, KAIST 함께 23에는 문제해결기법의 과제 해설만 공개된 경우가 포함된다. 전체 학기 완비 확인은 0이다.

공식 배포본과 학생 보관본을 표시한다. 학생 답안을 교수의 공식 정답으로 취급하지 않는다. 강의 일정·과제 평가 비율·Classroom 초대만으로 실제 자료 공개를 인정하지 않았다. 공개 영상은 공식 페이지에 녹화 링크가 있는 것을 확인했으며 재생 전체를 검증하지 않았다.

eTL은 사용자 지시로 제외했다. KAIST도 KLMS·Elice 등 로그인 강의실의 비공개 자료는 포함하지 않는다. SNU의 기존 공개 SNUON 소개 항목은 자료 미확인으로만 남아 있다.

링크 확인·표본 본문 확인·현재 접근 실패를 항목별로 표시했다. 646개 기존 링크를 재점검했고 C005/C007/C014/C099는 재접속에 성공했다. SNU-C002는 공개 강의 HTML만, SNU-C013의 과제 측은 프로젝트 지침만 확인했으며 C105는 PDF 파싱 실패로 미확인으로 정정했다. 404·이전 주소와 분류 변경은 [재검토 기록](reference/recheck-2026-11-04.md)에 적었다.

진입점에는 같은 과목의 학기별 페이지와 혼합 저장소가 포함되며 고유 과목 수와 다르다. 원문의 저작권·라이선스는 각 출처를 따른다.

## 관리 방식

JSON을 정본으로 삼고 Markdown 탐색 화면을 함께 갱신한다. 새 항목은 기존 ID를 재사용하지 않고 추가하며 확인일·학기 근거·실제 자료 링크·접근 한계를 기록한다. 새 공개 자료는 Issue 또는 브랜치 변경으로 제안할 수 있다. 검수는 고정 커밋을 기준으로 하며 자동 병합·예약 수집은 설정하지 않았다.
